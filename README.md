# ModernReader — 現代化閱讀器

專為知識工作者設計的現代化閱讀與內容管理工具（Project H.O.L.O.：多感官故事重建引擎）。

## 功能

- 純文字 Markdown 內容管理
- 分類資料夾（tech / biz / design 等）
- 日期命名自動歸檔（YYYYMMDD_ 前綴）
- 跨平台（任何 Markdown 閱讀器皆可開啟）

## 快速開始

```bash
git clone https://github.com/TeWei02/ModernReader.git
cd ModernReader
```

直接以支援 Markdown 的編輯器（VS Code、Typora 等）開啟即可閱讀。

## 目錄結構

```
ModernReader/
├── tech/       # 技術類內容
├── biz/        # 商業類內容
├── design/     # 設計類內容
└── README.md
```
